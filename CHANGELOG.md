# 4.0.0 (2026-05-08)

### Breaking Changes

* **elgg:** raise minimum to Elgg 4.x (PHP 8.1+). Plugins on Elgg 3.x must stay on hypevue 1.x.

### Migration (1.x → 4.x)

* **docker:** stack updated to `php:8.1-apache`, `mysql:5.7`, `elgg/elgg 4.3.6`.
* **ci:** added `.github/workflows/tests.yml` and `lint.yml`.
* **tests:** PHPUnit integration test suite (19 tests) verifying plugin activation and AMD module registration.

### Dependency Updates

* `elgg/elgg ^4.0`, PHP `>=8.1`, version bumped to `4.0.0`
