hypeVue
=======
![Elgg 7.x](https://img.shields.io/badge/Elgg-7.x-orange.svg?style=flat-square)

Vue.js bootstrap for Elgg

## Notes

To enable Vue dev tools, set ``environment`` config value to ``development``

```php
elgg_set_config('environment', 'development');
```

## Compatibility

| Plugin version | Elgg version |
|---|---|
| 7.0.0 | 7.x |
| 6.0.0 | 6.x |
| 5.0.0 | 5.x |
| 4.0.0 | 4.x |
